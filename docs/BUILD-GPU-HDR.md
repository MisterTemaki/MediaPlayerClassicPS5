# GPU/HDR build notes

Use Linux/WSL and a build path without spaces. This source archive contains application sources, licensed vendored code, shaders and assets; it does not include prebuilt external dependencies or a ready-made RADV SDK installation.

## Toolchain used

- Public ps5-payload-dev SDK 0.45 ([release](https://github.com/ps5-payload-dev/sdk/releases/tag/v0.45)), downloaded archive SHA-256 `5fac64093d0e3e69f2584ce7935f24f703f622d9681f1495c85b9f00d1291a2c`.
- Clang/LLD/LLVM 18.1.8 for the native build; glslangValidator 15.1.0 for shaders.
- GNU Make, Meson 1.10.1, Ninja, NASM, binutils, Python 3 and the host development packages listed in the main README. GCC/G++ 15.2.0 was used for existing host GPU tests.
- The 20 static dependencies in `FF_PS5_ARCHIVES`; versions, checksums and patches are pinned in `ps5/tools/build-deps.sh`.

## RADV prerequisite

Use `ps5/mitrt/platform/radv-shim/build-radv-mit.sh`, with explicit environment paths rather than the script's original developer defaults:

```sh
export VULKAN=/absolute/path/to/PS5_Vulkan
export SRC=/absolute/path/to/patched-mesa
export OPTIONS=/absolute/path/to/radv-ps5-release.radv-options
export CLC_BIN=/absolute/path/to/host-mesa-tools
export BUILD=/absolute/path/to/disposable-radv-build
bash ps5/mitrt/platform/radv-shim/build-radv-mit.sh /absolute/path/to/radv-mit
```

Prepare these inputs first using the PS5_Vulkan RADV tooling. `VULKAN` must contain its installed payload SDK fork and `tooling/radv/ps5-cross.ini`; `CLC_BIN` must contain `mesa_clc` and `vtn_bindgen2`. The build script clears its designated SDK/build directories, so select dedicated build output paths.

Pinned inputs for the delivered binary:

- Mesa commit `7b59ef27c1b09b9671bc4153c41940c3155c3af2`, plus PS5-ECAM 5.1.0 Mesa patches 0006–0009.
- Resulting Mesa tree `db544590b101bbf7f8940b0ec2feac6ee3e655c8` (the script checks `.tree`).
- Payload SDK fork commit `b83202be73e930050e00de0f1b4d9ec46c0391bf`, with its platform headers/archive replaced by the MIT headers included here.
- The selected release Meson options are in [RADV-PROVENANCE.txt](RADV-PROVENANCE.txt). The script also installs the matching Vulkan headers. Do not replace these inputs with arbitrary current revisions and assume identical behavior.

## Application

With all tools available on PATH and RADV prepared:

```sh
cd ps5
export PS5_PAYLOAD_SDK=/absolute/path/to/public-ps5-payload-sdk
bash tools/build-deps.sh ps5
make -j4 GPU=1 SLANG_GPU_RADV_MIT=/absolute/path/to/radv-mit ps5
```

See the Makefile output for the installer ELF and native package paths. Its preflights include app profile, imports, syscall and RADV linkage checks. `GPU=0` builds the software-renderer variant and is not the configuration of the supplied ELF.

Selected host regressions (after installing their host dependencies):

```sh
make test-audit HOST_CXX=clang++-18 DEPS_HEADERS=/absolute/path/to/prefix-ps5/include
make -j4 build/host/mpc-hdr-test build/host/mpc-gpu-library-test
VK_ICD_FILENAMES=/usr/share/vulkan/icd.d/lvp_icd.json VK_INSTANCE_LAYERS=VK_LAYER_KHRONOS_validation ASAN_OPTIONS=detect_leaks=0 build/host/mpc-hdr-test
```

The ICD filename varies by distribution. See the validation report for the checks actually executed. These notes record the build inputs and commands; a fresh independent build from this public source snapshot has not been performed. No signing private keys are included or generated by this packaging step.
